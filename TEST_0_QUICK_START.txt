Problem: Serial shows "MQTT connected" but dashboard not updating

Check:
  1. Browser console has "[MQTT] Message received"?
     → NO: See DEBUGGING_TEST_0.md section 2-6
     → YES: Hard refresh browser (Ctrl+Shift+R)

  2. .env.local has DEMO_MODE=false?
     → NO: Change to false, restart npm run dev
     → YES: Continue to #3

  3. Network tab shows WebSocket connected?
     → NO: Firewall blocking port 8884
     → YES: Continue to #4

  4. Topic match: ladet/data (both sides)?
     → NO: Fix mismatch, re-upload firmware
     → YES: Full restart (ESP32 + website + browser)
